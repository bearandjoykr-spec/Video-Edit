# Reference reel — cinematic grammar

Source: https://www.instagram.com/reel/DfMxl9QpHuP/ (public; downloaded with yt-dlp to
`references/cinematic/ref_DfMxl9QpHuP.mp4`, git-ignored). 105 s, 1920×1014 (≈1.89:1, already
letterboxed), 24 fps.

## Structure (105 s)
| Time | Beat | Look |
|---|---|---|
| 0–2 s | Black, then archival group photo small in frame | B/W, film dust |
| 2–14 s | Cold open: profile at a palace, archival crowds, raised hands | B/W, grain, flicker |
| 14–19 s | Wall of text / symbol, red subtitles over crowd texture | B/W + red type |
| 19–26 s | Volcano / fire → hard cut to colour | first colour = hot orange |
| 26–40 s | Hero at Gwanghwamun, wide → mid; "Seoul, Korea" location super | clean warm colour |
| 40–60 s | Chase/journey: whip pans, low tracking, speed ramps, prop (red case) as through-line | handheld, motion blur |
| 60–80 s | New city, new people find the case — "Oita, Japan", "Tokyo, Japan" supers; poster reveal | grain, teal/orange |
| 80–95 s | Montage of the message spreading (posters everywhere), embraces | fast cuts, 1–1.5 s each |
| 95–100 s | Title: Korean + Japanese flags waving behind red title | |
| 100–105 s | Black end card, red bold sans "2026.11.20. OITA" | |

## Type
- **Big statement title:** one language huge (thin, tall serif, cream-white), the other languages
  small underneath, stacked: small Korean line, then English line. Left-aligned, left third.
- **Subtitles under texture:** three languages in one row, red condensed serif. Restrained, no boxes,
  no shadows to speak of.
- **Location supers:** large condensed serif, cream, lower-left ("Seoul, Korea").
- **End card:** black, bold red caps sans, tiny caps line above.

## Takeaways for Bear & Joy
- Open in black-and-white "past", break into colour for "present".
- A prop as through-line; place supers announce each city.
- Small Korean line above English, clean serif, no boxes, generous negative space.
- Letterbox ~1.89–2.39:1 on the landscape cut; titles on black between beats.
- Fast montage near the end, then title, then black end card.
